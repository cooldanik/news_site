
# News Portal

## Описание

**News Portal** — современный новостной веб-сайт, разработанный с использованием Django. Проект предоставляет пользователям возможность просматривать новости, искать публикации, фильтровать их по категориям и взаимодействовать с материалами через систему комментариев.

Приложение реализовано в соответствии с архитектурой Django и использует встроенную систему аутентификации, ORM и шаблоны Django.

---

# Возможности

### Для всех пользователей

* просмотр последних новостей;
* просмотр популярных новостей;
* чтение полной версии публикаций;
* поиск новостей;
* просмотр новостей по категориям;
* регистрация и авторизация.

### Для авторизованных пользователей

* добавление комментариев;
* редактирование собственных комментариев;
* удаление собственных комментариев;
* управление личным профилем.

### Для администратора

* создание, редактирование и удаление новостей;
* управление категориями;
* управление комментариями;
* управление пользователями через административную панель Django.

# Установка

## Клонирование репозитория

```bash
git clone <repository_url>
cd news_portal
```

## Создание виртуального окружения

Windows

```bash
python -m venv venv
venv\Scripts\activate
```

Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Выполнение миграций

```bash
python manage.py migrate
```

## Создание администратора

```bash
python manage.py createsuperuser
```

## Запуск проекта

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000/
```
